# Review Stage (04-review)

## Overview
This project manages code review, architectural sign-off, security audit compliance, and deployment readiness review.

## Agent Roles & Responsibilities
- **Code Reviewer**: Evaluate code quality, conventions, readability, and test coverage.
- **Security & Compliance Auditor**: Audit dependencies, credentials, and potential vulnerabilities.
- **Release Coordinator**: Verify deployment checklist, release notes, and final sign-off.

## Guidelines
- Ensure all QA checks from `03-qa` have passed.
- Maintain a clear audit trail of review comments, approvals, and sign-offs.
- Prepare post-release retrospectives and notes.
