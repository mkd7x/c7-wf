# Execution Stage (02-exe)

## Overview
This project handles the implementation, coding, and development activities based on specs from the planning phase.

## Agent Roles & Responsibilities
- **Lead Implementer**: Write core feature code following architectural guidelines and best practices.
- **Refactoring Agent**: Ensure clean code structure, maintainability, and pattern consistency.
- **Integration Engineer**: Manage dependencies, build pipelines, and external integrations.

## Guidelines
- Adhere strictly to the specs produced in `01-plan`.
- Write unit tests alongside feature implementation.
- Prepare code and artifacts for verification in `03-qa`.
